# ☕ Vintage Tea Corner


A vintage Bengali tea-shop themed website inspired by the traditional **চায়ের দোকান (Tea Stall)** culture of Bengal.

The website combines a warm vintage design with a **YouTube Playlist Music Player**, creating a cozy tea-stall atmosphere with music.

---

## 🌿 About the Project

**মিন্টুর চা (Mintur Cha)** is a frontend web project designed around the feeling of a traditional Bengali tea stall.

The website features:

- ☕ Vintage tea-shop aesthetic
- 🇧🇩 Bengali typography
- 🎵 YouTube playlist music player
- ▶️ Play / Pause controls
- ⏮ Previous / Next song
- 🔊 Volume control
- 🔇 Mute / Unmute
- ⏱️ Music progress bar
- 🎨 Cinematic background
- 📱 Responsive design
- 🌙 Dark vintage color palette

---

## ✨ Features

### ☕ Vintage UI

The design uses warm colors such as:

- Dark Brown
- Vintage Red
- Cream
- Golden Yellow

This creates a traditional **চায়ের দোকান** atmosphere.

### 🎵 YouTube Music Player

The website integrates the **YouTube IFrame Player API**.

Users can:

- Play songs
- Pause songs
- Skip to the next song
- Go back to the previous song
- Adjust volume
- Mute/unmute
- Seek through the song
- Load a YouTube playlist

### 📱 Responsive Design

The website is designed to work on:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📱 Tablet
